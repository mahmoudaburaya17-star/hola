# الدرس 2: من أنا؟ — Yo soy…

## أهداف الدرس
- تستخدم الضمائر والفعل **ser** (يكون).
- تفهم المذكر والمؤنث والجمع.
- تقول جنسيتك ومهنتك.

## 1) الضمائر

| الإسباني | العربي |
|---|---|
| yo | أنا |
| tú | أنتَ / أنتِ (غير رسمي) |
| él / ella | هو / هي |
| usted | حضرتك (رسمي) |
| nosotros / nosotras | نحن (مذكر / مؤنث) |
| vosotros / vosotras | أنتم (إسبانيا فقط) |
| ellos / ellas | هم / هن |
| ustedes | أنتم (رسمي، وكل الأمريكتين) |

مفيش مثنّى في الإسبانية. "اثنين" بتتعامل جمع.

## 2) الفعل ser

| الضمير | ser |
|---|---|
| yo | soy |
| tú | eres |
| él / ella / usted | es |
| nosotros/as | somos |
| vosotros/as | sois |
| ellos / ellas / ustedes | son |

في العربية بنحذف "يكون" في الحاضر ("أنا مصري"). في الإسبانية لازم الفعل: **Soy egipcio.**
وزي العربية، الضمير ممكن يتحذف لأن الفعل بيدل عليه: **Soy estudiante.**

## 3) المذكر والمؤنث
- أغلب الأسماء اللي بتنتهي بـ **-o** مذكر، وبـ **-a** مؤنث: el libro، la casa.
- في استثناءات: **el día** (مذكر)، **la mano** (مؤنثة)، **el problema** (مذكر).
- أدوات التعريف: **el / la** (ال)، وفي الجمع **los / las**.
- أدوات التنكير: **un / una** (في العربية ما عندناش تنكير بحرف، لكن الإسبانية عندها).

### الجمع
- ينتهي بحرف متحرك: أضف **-s** → casa → casas
- ينتهي بحرف ساكن: أضف **-es** → ciudad → ciudades
- ينتهي بـ z: تتحول **c** + es → lápiz → lápices

### الصفة بتتبع الاسم (زي العربية)
- الصفة غالبًا **بعد** الاسم: **un profesor egipcio** (مثل: أستاذ مصري).
- وبتتوافق معاه في النوع والعدد: **una profesora egipcia / profesores egipcios**.

## 5) مهن
médico/médica (طبيب)، ingeniero/ingeniera (مهندس)، profesor/profesora (مدرس)، estudiante (طالب، نفس الشكل للجنسين)، abogado/abogada (محامي)، periodista (صحفي، نفس الشكل).

## 6) حوار

**—¿Eres egipcia?**
**—Sí, soy egipcia. Soy de Alejandría.**
**—¿Y qué eres?**
**—Soy ingeniera. ¿Y tú?**
**—Soy médico. Mi amigo es profesor.**

## 7) تمارين

**أ.** أكمل بالفعل ser:
1. Yo ____ egipcio.
2. Ella ____ médica.
3. Nosotros ____ estudiantes.
4. Ustedes ____ de Jordania.
5. Tú ____ profesor.

**ب.** اختار الشكل الصحيح:
1. Ella es (marroquí / marroquía).
2. Mi amigo es (libanés / libanesa).
3. Las profesoras son (egipcios / egipcias).

**ج.** اجمع: un libro, una ciudad, un país, un lápiz.

**د.** ترجم: «أنا طالبة مصرية.» → ______

## الإجابات
**أ.** 1) soy 2) es 3) somos 4) son 5) eres
**ب.** 1) marroquí 2) libanés 3) egipcias
**ج.** unos libros, unas ciudades, unos países, unos lápices
**د.** Soy estudiante egipcia.
