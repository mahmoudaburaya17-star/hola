# الدرس 6: الأماكن والاتجاهات — Lugares y direcciones

## أهداف الدرس
- تسأل عن مكان وتفهم الرد.
- تفرّق بين **estar** و**hay**.
- تستخدم الفعل **ir** (يذهب).

## 1) أماكن

| الإسباني | العربي |
|---|---|
| la estación | المحطة |
| el aeropuerto | المطار |
| el hotel | الفندق |
| el banco | البنك |
| la farmacia | الصيدلية |
| el hospital | المستشفى |
| la mezquita | المسجد |
| el supermercado | السوبر ماركت |
| la calle | الشارع |
| el baño / los servicios | الحمام |

## 2) الفعل estar (يوجد/يتواجد)
بنستخدمه للمكان والحالة المؤقتة:

| الضمير | estar |
|---|---|
| yo | estoy |
| tú | estás |
| él / ella / usted | está |
| nosotros/as | estamos |
| vosotros/as | estáis |
| ellos / ellas / ustedes | están |

**¿Dónde está el hotel?** — **El hotel está en la calle principal.**
**Estoy cansado.** (حالة مؤقتة)

### الفرق بين ser و estar (مبسط)
- **ser**: الهوية، الجنسية، المهنة، الصفات الثابتة: *Soy egipcio. Es alta.*
- **estar**: المكان والحالة المؤقتة: *Estoy en Madrid. Estoy cansado.*

## 3) hay
**hay** = "فيه / يوجد" وبتتقال مع شيء غير محدد. شكلها ثابت للمفرد والجمع:
- **Hay una farmacia cerca.** (فيه صيدلية قريبة)
- **Hay dos bancos en la calle.**
- السؤال: **¿Hay un baño por aquí?**

القاعدة: لو الشيء محدد (el hotel، la estación) → **está**. لو غير محدد (una farmacia، dos bancos) → **hay**.

## 4) الفعل ir

| الضمير | ir |
|---|---|
| yo | voy |
| tú | vas |
| él / ella / usted | va |
| nosotros/as | vamos |
| vosotros/as | vais |
| ellos / ellas / ustedes | van |

**Voy a la farmacia.** (a + la)
**Voy al banco.** (a + el = **al**)
**Vamos a la mezquita.**
**Voy a estudiar.** = هذاكر (المستقبل القريب: ir + a + مصدر)

بالمثل: **de + el = del**: *Vengo del hotel.*

## 5) اتجاهات
- a la derecha = يمين
- a la izquierda = شمال
- todo recto / todo derecho = على طول
- cerca de = قريب من
- lejos de = بعيد عن
- al lado de = جنب
- enfrente de = قدّام
- gira / doble = لف

## 6) حوار

**—Perdone, ¿dónde está la farmacia?**
**—Está cerca. Siga todo recto y luego gire a la derecha.**
**—¿Está lejos?**
**—No, está a cinco minutos andando.**
**—Muchas gracias.**
**—De nada.**
