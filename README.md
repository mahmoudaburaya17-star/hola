# إسبانيول للعرب — Español para hablantes de árabe (A1)

كورس مجاني لتعلم الإسبانية من الصفر للمتحدثين بالعربية (مصريين وعرب). الشرح بعربية مبسطة، والمقارنات دايمًا مع العربية لأن فيه تشابه كبير بينهم (تصريف الأفعال، المذكر والمؤنث، الصفة بعد الموصوف، وكلمات كتير من أصل عربي).

كل درس فيه: أهداف، مفردات مع نطق تقريبي بالحروف العربية، شرح قواعد، حوار، تمارين، وإجابات.

## ملاحظات مهمة

- النطق بالحروف العربية **تقريبي** ومش بديل عن السماع. استمع لمتحدثين أصليين.
- الدروس متوافقة مع مستوى A1 في الإطار الأوروبي المرجعي (CEFR) وخطوط Plan curricular del Instituto Cervantes العريضة. التفاصيل في [SOURCES.md](SOURCES.md).
- المحتوى مكتوب أصلًا لهذا الكورس، مش منقول من كتاب. يُفضّل مراجعة مدرس إسبانية قبل النشر التجاري.
- الإسبانية المستخدمة محايدة، وبنشير للفروق بين إسبانيا وأمريكا اللاتينية لما تكون مهمة (مثل vosotros وzumo/jugo).

## خطة التوسع

A2: الماضي (pretérito), المستقبل القريب, السفر والصحة. B1 بعدها.
